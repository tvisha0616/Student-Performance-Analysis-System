# Student Performance Analysis System

A Python-based Student Performance Analysis System developed for the Computational Thinking and Programming project at Bennett University.

## Project Description

This project analyses the academic performance of multiple students across five subjects. It calculates total marks, averages, assigns grades, identifies weak subjects, and finds the highest and lowest performers.

## Features

- Student marks management
- Total and average calculation
- Automatic grade assignment
- Performance evaluation
- Subject-wise average calculation
- Identification of topper and lowest performer
- Class performance report
